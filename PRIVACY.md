# Privacy Policy

Last updated: August 17, 2026

ChatGPT RTL Open Source is designed to operate entirely inside the user's browser.

## Data collection

The extension does not collect, store, transmit, sell, or share personal information, chat content, browsing history, usage analytics, or any other user data.

## Local operation

The extension modifies text-direction styling on `chatgpt.com`. It makes no network requests and has no server-side component. The current RTL/LTR mode exists only in the open page and is discarded when the page is fully reloaded or closed.

## Permissions

The extension requests no Chrome API permissions. Its content script is limited to `https://chatgpt.com/*`, where it provides its single text-direction feature.

## Changes

If this policy or the extension's data practices change, the updated policy will be published with the project before a release containing those changes.

## Contact

Support and privacy questions can be submitted through the public GitHub repository after it is published.
